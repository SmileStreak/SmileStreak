# SmileStreak store icon artwork

- `apple-app-store-icon-1024.png`: 1024 × 1024 PNG for the App Store icon upload.
- `google-play-icon-512.png`: 512 × 512 PNG for the Play Store app icon upload.

Both use the approved black “smile” and green “streak” wordmark on a solid warm cream square. The artwork has no baked-in rounded corners; each store applies its own mask.
